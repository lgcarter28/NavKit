# Engineering Hardware and Local AI Trade Study

This directory contains a dated, decision-oriented trade study for the portable
development workstation and expandable Linux compute server intended to support
NavKit development, local LLM inference, simulation campaigns, analysis,
future vision navigation, and later factor-graph workloads.

Build the document from this directory with:

```powershell
latexmk -pdf -interaction=nonstopmode -halt-on-error main.tex
```

The component prices are planning bands, not purchasing quotes. Recheck market
prices, physical dimensions, power connectors, and vendor support immediately
before ordering.
